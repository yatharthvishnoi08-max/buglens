# BugLens: all reports in one place

[Download the complete documentation ZIP](Complete_Documentation_Package.zip).

This is the single file to share for full project documentation. It contains the project README, all documentation and evidence assets, editable Mermaid diagrams, rendered diagrams, the submission PDF and a navigation index.
